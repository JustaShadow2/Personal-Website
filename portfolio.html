Featured experience — Kouano

Open-weight, self-hosted, API-first music generation. Everything below is what I designed and engineered — product UI, inference API, quality gating, editing, stems, and provenance. Private beta.

Founder & Software Engineer — Kouano

2026 – Present · Generative Audio / Full-Stack AI

Kouano turns a text prompt (and optional lyrics) into finished, mastered songs — then lets creators edit, extend, separate stems, and export, while exposing the same engine as a public REST API for developers who want to self-host open weights.

What I built (product)

  • End-to-end creator loop: Create → Generating → Result → Editor, with dual-take comparison, Web Audio players, non-destructive version history, download (MP3/WAV), share, and “How this was made” provenance UI.
  • Marketing + app + developer surface on one design system: persona toggle (creators / developers), pricing tiers, FAQ, trust/privacy messaging, light/dark, responsive, AA-minded contrast and reduced-motion support.
  • Smart defaults for time-to-first-song: single prompt, Surprise-me + examples, Advanced panel for seed / steps / guidance / Studio tier.

What I built (systems & ML infra)

  • ACE-Step DiT serving stack with model registry (turbo / SFT / base DiT variants + 0.6B lyric LM), health/readiness reporting, local song storage backend, and production-oriented perf knobs (FP8 weight-only DiT quantization, compiled DiT, concurrency + queue limits).
  • Compose pipeline (POST /v1/compose): free-text prompt, optional lyrics (null → model writes lyrics via CoT), instrumental flag, duration up to 4 minutes on Turbo, CFG + denoising steps, seed-reproducible multi-take generation.
  • CLAP best-of-N quality gate: generate n + overgenerate takes, score/rerank, discard losers, return winners with CLAP scores, timings, LUFS, and SLA flags — surfaced in-product as “we kept your best takes.”
  • Lyric integrity loop: optional ASR verification so takes actually sing provided lyrics; regenerate until the gate’s quota of valid vocal takes is met.
  • M2 editing API: cover/remix, time-bounded section repaint (latent + WAV crossfades, strength/strategy controls), worker extend, and multi-hop orchestrated extend (async jobs with overlap stitching so tracks truly lengthen).
  • Stem separation: MelBand-RoFormer / BS-RoFormer primary engines with Demucs fallback; per-stem fetch, instrumental stem, and Studio stems.zip for vocals/drums/bass/synths/FX/master.
  • Provenance & ownership: per-track record of models, settings, and exact seeds; inaudible watermark; commercial-ready exports; open-weight self-host path so prompts stay private and never become training data.
  • Developer API surface: OpenAPI-documented REST (sync generate + compose, streaming-oriented design, stems + provenance endpoints) — same engine as the app, intended for product embedding and on-prem GPUs / white-label.

Stack highlights: ACE-Step DiT + lyric LM · CLAP reranking · RoFormer/Demucs separation · FastAPI-style REST/OpenAPI · Web Audio · React design-component UI · GPU inference (FP8, compiled) · async job orchestration

PokeQuant — Pokemon TCG Quantitative Analytics

Personal Project · Data / ML / Full-Stack

Quantitative market platform for Pokemon TCG: nightly price pipelines across TCGPlayer and eBay (raw + graded), ML fair-value predictions with confidence intervals, demand/momentum signals, PSA grading ROI, sealed-product tracking, and leaderboards across Scarlet & Violet–era cards and sets.

  • Built card/set/sealed explorers with multi-source price history charts (TCGPlayer market, eBay raw averages, PSA 9 / PSA 10 smart prices) and volume views (TCGPlayer sales + 7-day PSA 10 eBay volume).
  • Implemented ML fair-value model outputs per card: predicted price, 90% CI bounds, UNDERVALUED / FAIR VALUE / OVERVALUED signal, prediction confidence, and ratio vs market — filterable and rankable in the UI.
  • Engineered demand scoring (0–10 composite from search interest + 14d/30d price momentum) and PSA 10 grading ROI (smart graded price ÷ raw eBay), with confidence based on sold-listing sample size.
  • Designed data model around snapshot tables for prices, eBay graded metrics, sales, demand signals, sealed products, and versioned model_predictions for reproducible nightly refreshes.
  • Shipped leaderboards ranking cards by momentum, PSA 10 ROI, and sales volume; sets by cultural/premium metrics and 30-day movement; sealed booster boxes/ETBs/packs by price and change.

Stack highlights: Next.js · TypeScript · Supabase/Postgres snapshot store · time-series market ingestion · ML regression / fair-value signals · Recharts-style analytics UI
