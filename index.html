Founder & Software Engineer — Kouano

2026 – Present

Built an open-weight, self-hosted, API-first music generation product: prompt → mastered song over REST, with a creator app, quality-gated multi-take generation, stem separation, non-destructive editing, and auditable provenance.

  • Shipped the full product surface: marketing landing, Create → Generating → Result → Editor loop, Web Audio playback, download/share flows, light/dark theming, and a documented design system (WCAG AA–minded).
  • Implemented the production ACE-Step inference API (OpenAPI 3.1, M1 compose + M2 edits/stems): POST /v1/compose, sync /v1/generate, cover / repaint / extend, audio + metadata + provenance endpoints, and stem listing/zip download.
  • Engineered a best-of-N CLAP quality gate: over-generate takes (default n=2, overgenerate=1), score with CLAP, discard weak takes, return winners with seed-reproducible provenance (models, settings, exact seeds).
  • Built Turbo DiT serving (acestep-v15-xl-turbo) with FP8 weight-only quantization, compiled DiT, concurrency/queue controls, 48 kHz stereo mastering, LUFS targeting, and soft latency SLAs (~15s compose budget; sub-10s path for Quick tier).
  • Added lyric CoT generation, optional ASR lyric verification/retry, instrumental mode, Quick vs Studio tiers (stems, per-section control, higher-effort vocals), and seed/CFG/steps advanced controls.
  • Implemented M2 editing complexity: section repaint (latent + WAV crossfades), cover/remix, and multi-hop extend via an async orchestrator (job create → poll → load finished audio) so tracks actually lengthen beyond turbo repaint.
  • Integrated multi-engine stem separation (MelBand RoFormer / BS-RoFormer primary path with Demucs fallback), instrumental stem fetch, and Studio stem ZIP export for DAW use.
  • Designed privacy/ownership primitives: prompts not used for training, open weights for self-host/white-label, inaudible provenance watermark, commercial-ready MP3/WAV exports, and consent-first stance (no unconsented voice cloning).
